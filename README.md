# 🚗 Автопрокат автомобилей

## 📌 О проекте

Данный проект посвящён разработке концепции приложения для аренды автомобилей.

Приложение предназначено для клиентов, которые хотят быстро найти подходящий автомобиль, ознакомиться с его характеристиками и стоимостью аренды, а также оформить аренду.

Проект выполнен в рамках лабораторной работы №1.

---

## 🎯 Цель проекта

Создать удобную систему для поиска и аренды автомобилей, которая позволит:

* просматривать доступные автомобили;
* смотреть характеристики автомобилей;
* узнавать стоимость аренды;
* выбирать дату аренды;
* оформлять заказ на автомобиль;
* управлять информацией об автомобилях.

---

## 👤 Целевая аудитория

Основными пользователями приложения являются:

## 📋 Основные функции

### Для клиента

1. Просмотр списка автомобилей.
2. Просмотр информации об автомобиле.
3. Выбор даты аренды.
4. Проверка доступности автомобиля.
5. Оформление аренды.

### Для администратора

1. Добавление автомобиля.
2. Изменение информации об автомобиле.
3. Удаление автомобиля.
4. Изменение статуса автомобиля.
5. Просмотр арендованных автомобилей.

## 👥 Пользовательские истории

### Клиент

> Как клиент, я хочу просматривать доступные автомобили, чтобы выбрать подходящий автомобиль для аренды.

> Как клиент, я хочу видеть стоимость аренды, чтобы понимать свои расходы.

> Как клиент, я хочу выбрать дату аренды, чтобы забронировать автомобиль на нужный период.

### Администратор

> Как администратор, я хочу добавлять автомобили в систему, чтобы пользователи могли их арендовать.

> Как администратор, я хочу изменять статус автомобиля, чтобы показывать, свободен он или уже арендован.

---

## 💡 Основная проблема

Клиенту необходимо быстро найти подходящий автомобиль для аренды и получить всю необходимую информацию в одном месте.

Приложение должно сделать процесс выбора и аренды автомобиля более понятным и удобным.
